# 鐘點戰 (Time War)

多人同時連線的時間生存遊戲。

## 啟動
    npm install
    npm start          # 預設 http://localhost:3000，可用 PORT=xxxx 更改
同一網路的玩家用 `http://<主機IP>:3000` 連入；若要上網遊玩，部署到任何支援 Node.js 與 WebSocket 的主機即可。

## 規則
- 第一位進入的人是房主（房主離線會自動轉給下一位），按「遊戲開始」後每人隨機分配 10~20 分鐘，3 秒倒數後開始。
- 隱藏卡片：房主在「卡片設定」新增/修改/刪除卡片（正數加時間、負數為懲罰），把密碼寫在卡片上藏起來。
- 分享時間：輸入時間後確認，立刻扣除並產生四碼密碼，隊友輸入即可獲得；不能自己使用。
- 所有密碼只能使用一次；連續輸錯 5 次鎖定 15 秒（防止暴力猜密碼）。
- 時間歸零 → GAME OVER；最後存活者 → YOU WIN；結束後點「重新啟動遊戲」回等候室。
- 每局開始時卡片自動重置為未使用（密碼不變），上一局的分享密碼全部作廢。
